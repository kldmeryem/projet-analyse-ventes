\# Projet d'analyse de ventes (SQL + Python)



Analyse des ventes d'une boutique en ligne avec SQLite, Python, pandas et matplotlib.



\## Objectifs



\- Concevoir une base de données relationnelle (clients, produits, commandes)

\- Écrire des requêtes SQL analytiques (jointures, agrégations)

\- Visualiser les résultats avec Python



\## Technologies



\- Python 3

\- SQLite

\- pandas

\- matplotlib



\## Structure du projet



\- `creer\_bdd.py` : création de la base `ventes.db` et génération de données de test

\- `analyse.py` : requêtes SQL (top clients, CA par catégorie)

\- `graphiques.py` : génération des graphiques



\## Lancer le projet



```bash

pip install pandas matplotlib

python creer\_bdd.py

python analyse.py

python graphiques.py

```
